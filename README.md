# SlimLog 減肥追蹤器

## 部署到 GitHub Pages

1. 登入 [github.com](https://github.com)
2. 右上角 **+** → **New repository**
   - Repository name: `slimlog`（或任何名字）
   - 設為 **Public**
   - 按 **Create repository**
3. 進入 repository → 按 **uploading an existing file**
4. 將 `index.html`、`sw.js`、`manifest.json`、`icon-192.png`、`icon-512.png` 全部拖進去
5. 按 **Commit changes**
6. 去 **Settings** → **Pages** → Source 選 **main branch** → Save
7. 等約 1 分鐘，網址會係：`https://你的用戶名.github.io/slimlog/`

## 加入 iPhone 主畫面

1. 用 Safari 打開網址
2. 底部「分享」→「加入主畫面」
